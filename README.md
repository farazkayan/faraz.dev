\## How I build



I use AI heavily as part of my development workflow.



I brainstorm with real people and AI, break ideas into phases, plan them out, then build one piece at a time. When something breaks, I try to understand the problem first, use AI to help pinpoint the failure, fix it, and learn from what happened.



Some of the tools I've experimented with include:



\* Kilo Code

\* Roo Code

\* Claude

\* Gemini

\* Aider

\* NVIDIA NIM

\* LM Studio



AI doesn't replace the learning for me — it's part of how I learn faster and build more.
